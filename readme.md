# 📝 To-Do List Web App — v1.0  

A simple yet fully functional **To-Do List** web app built using **HTML, CSS, and JavaScript**.  
This project focuses on learning **DOM manipulation**, **localStorage persistence**, and **responsive UI design**.  

---

## 🚀 Features  

- ✅ **Add New Tasks** using a modal input window  
- ✅ **Mark Tasks as Complete / Incomplete** with a single checkbox toggle  
- ✅ **Persistent Storage** — all tasks are saved in `localStorage` (no data loss on reload)  
- ✅ **Delete Tasks** from both To-Do and Completed lists  
- ✅ **Keyboard Shortcuts**  
  - **Enter** → Add Task  
  - **Escape** → Cancel / Close modal  
- ✅ **Responsive Layout** for all screen sizes  
- ✅ **Clean & Minimal Design** using Flexbox  

---

## 🧠 What’s New in v1.0

## 🧭 How to Use  

1. **Clone or Download** this repository  
2. Open `index.html` directly in your browser  
3. Click the ➕ **floating button** to add new tasks  
4. Use checkboxes to **mark tasks complete or undo them**  
5. Use the 🗑️ icon to delete tasks
